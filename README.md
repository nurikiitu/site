# Ауыл дәмі — құрт, қазы, май (Астана)

Бір беттік дүкен: салмақты таңдау → себет → мекенжай → WhatsApp-қа тапсырыс → Kaspi аударым экраны.

## Баптау (`index.html` ішінде)
- `WA` — тапсырыс келетін WhatsApp нөмірі
- `FREE_KG`, `DELIVERY` — тегін жеткізу шегі (2 кг) және ақысы (1000 ₸)
- `P` — өнімдер тізімі мен бағалары
- `KASPI_PHONE`, `KASPI_OWNER` — Kaspi аударым нөмірі мен иесінің аты

## Фото
`img/<id>.jpg` файлын салсаңыз (мысалы `img/kazy.jpg`), сурет орнына фото шығады.
